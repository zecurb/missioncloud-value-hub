# Demo Scenario

The fictional company Northstar Commerce operates Azure workloads across commerce, analytics, shared services, and security. Monthly cloud spend is $184,250. Leadership wants to reduce waste while preserving reliability and growth capacity.

The Phase 1 dashboard shows:

- $428,400 in identified annual savings
- $27,650 in verified monthly realized savings
- 18 open opportunities
- 94.7% allocation coverage
- 91.2% policy compliance

The highest-value opportunities include compute rightsizing, database commitments, unattached disk cleanup, and storage lifecycle policies.
