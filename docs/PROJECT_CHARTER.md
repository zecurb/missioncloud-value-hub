# Project Charter

## Product statement

MissionCloud Value Hub is an internal enterprise FinOps portal that translates multi-source cloud economics into prioritized, accountable, and measurable business outcomes.

## Primary users

1. Executives — value realization, budget exposure, strategic tradeoffs
2. Finance — forecasting, allocation, showback/chargeback, variance analysis
3. Program managers — initiative tracking, ownership, delivery risk
4. Engineers — technically actionable optimization recommendations
5. Security and governance — policy compliance and exception visibility
6. Administrators — source configuration, identity, RBAC, audit controls

## Differentiators

- Measures realized value, not only theoretical savings
- Connects recommendations to owners, status, risk, and evidence
- Supports executive, finance, and engineering workflows in one product
- Treats governance and operational risk as first-class optimization constraints
- Designed for Azure, Kusto, Kion, and enterprise integration patterns

## Phase 1 success criteria

- A developer can enter the Nix shell and install dependencies from documented commands.
- The API exposes health, summary, and optimization opportunity endpoints.
- The dashboard renders API-backed executive KPIs and ranked opportunities.
- Automated API tests pass.
- CI definitions validate Python and TypeScript changes.
- Implemented features and future plans are clearly separated.
